Local alignment: find the part that matches

Two sequences can share one conserved region and nothing else: a protein domain, a regulatory motif, an exon. Global alignment forces the whole length to align and buries that signal. The Smith-Waterman algorithm (1981) finds the best-scoring region only, using the same matrix as Needleman-Wunsch with three small changes.

1

Three changes turn global into local

0
A floor of zero

Every cell takes the maximum of the three usual options and zero. A negative running score is reset, so a bad region never drags down a good one that follows.

0 0 0
First row and column are zero

The alignment may start anywhere, so leaving out the beginning of either sequence costs nothing.

max
Traceback from the highest cell

Start at the highest value anywhere in the matrix and follow the arrows until you reach a zero. That stretch is the local alignment.

S(i, j) = max { 0, S(i−1, j−1) + s(aᵢ, bⱼ), S(i−1, j) + gap, S(i, j−1) + gap }
Compare with Module 3: the only change in the formula is the zero.

3

Traceback

Local: start at the highest cell and stop at the first zero. Global: start at the bottom-right cell and stop at the top-left. The positions show which part of each sequence the alignment covers.

Fill the whole matrix in section 2 first.

If several cells share the highest value, there are several equally good local alignments, often in different regions of the sequences. Programs such as EMBOSS Water report one; BLAST, which you will meet in Module 6, reports every region that scores above a threshold.

A rule for scoring schemes: local alignment only works when a random alignment scores negative on average. If mismatches cost nothing, the running score rarely drops to zero, the "local" alignment spreads across unrelated sequence, and it behaves almost like a global one. Choose the lenient scheme above to see this happen.
