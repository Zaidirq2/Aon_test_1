How do we know which alignment is best?

Every pair of sequences can be aligned in thousands of ways. A scoring scheme turns each alignment into a single number, so the algorithms in the next modules can search for the highest one. Change the scheme and the "best" alignment can change with it.

The same two sequences, aligned two ways. Both have 8 matches and 2 gap positions. Is one gap of length 2 better than two gaps of length 1? Only the scoring scheme can decide.
1

The three ingredients of a score

An alignment score is the sum of the scores of its columns. Each column is one of three things:

A match (same base in both sequences) receives a positive score, because related sequences share bases more often than random sequences do. A mismatch receives a negative score. In DNA it is common to penalise transversions (purine ↔ pyrimidine) more than transitions (A↔G, C↔T), because transitions occur more often in real genomes. A gap receives a negative score that depends on its length.

Score = Σ match scores + Σ mismatch scores + Σ gap penalties. The algorithm does not "understand" biology: it only maximises this sum. Biology enters through the numbers you choose.

Linear versus affine gap penalties

A linear gap penalty charges the same amount for every gap position, so one gap of length 3 costs the same as three separate gaps of length 1. An affine gap penalty charges a large cost to open a gap and a smaller cost to extend it. This matches biology: a single insertion or deletion event often adds or removes several bases at once, so one long gap is more plausible than many short ones.

The chart uses the opening and extension values from section 2.

linear: length × openingaffine: opening + (length − 1) × extension

Conventions differ between programs. Some define the cost of a gap of length L as open + L × extend, others as open + (L − 1) × extend. Always check the documentation before comparing scores between tools.
4

End gaps: global, semi-global and local alignment

Suppose you sequenced a short fragment and want to know where it sits in a longer gene. A global alignment forces both sequences to be aligned from first base to last, so the long overhangs are paid for as gaps. If end gaps are free, the fragment can sit anywhere inside the gene without penalty. This is called semi-global (or "glocal") alignment.

Scoring here: match +1, mismatch −1, gap opening −3, gap extension −1. Fragment: HBB c.16–27. Gene: HBB c.1–45.

Three questions, three types of alignment.
Are these two sequences similar along their whole length? → Global (Needleman-Wunsch, Module 3).
Where does this short sequence sit inside a longer one? → Semi-global (free end gaps).
Do these two sequences share any similar region, even if the rest is unrelated? → Local (Smith-Waterman, Module 4).
