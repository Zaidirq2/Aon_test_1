# Experiment 2: Digital Modulation Techniques (web version)

`index.html` is a browser port of `experiment2.m`: BPSK, QPSK and 16-QAM over an
AWGN channel, with ideal and received constellations, simulated vs theoretical
BER vs SNR, and data rate vs modulation order. Open the file in any browser
(it loads Plotly from cdn.plot.ly for the figures); no MATLAB needed.
